# Nearby

ส่งไฟล์และข้อความระหว่างอุปกรณ์ใกล้ ๆ กัน ผ่านเบราว์เซอร์ ไม่ต้องติดตั้ง ไม่ต้องสมัคร ไฟล์ไม่ถูกอัปโหลดขึ้น server
Share files and text between nearby devices, right in the browser. No install, no account, nothing uploaded.

**เว็บ / Live:** https://devgreenpink.github.io/nearby/

## เริ่มใช้งาน / Quick start

1. เปิดเว็บบนทั้งสองเครื่อง ถ้าต่อ Wi‑Fi เดียวกัน จะเห็นกันบนเรดาร์เอง
2. แตะเครื่องที่ต้องการบนเรดาร์ แล้วกด **ส่งไฟล์** หรือ **ส่งข้อความ** (หรือลากไฟล์มาวาง / กด Ctrl+V)
3. อีกเครื่องกด **รับ** ไฟล์ก็วิ่งตรงถึงกัน

ครั้งแรกแอปจะสุ่มชื่ออวกาศ ตัวละคร และสีให้เอง จึงใช้ได้ทันทีโดยไม่ต้องตั้งค่า เปลี่ยนเองได้ทีหลังจากปุ่มตัวเราตรงกลางเรดาร์

Open it on both devices (same Wi‑Fi = they appear automatically), tap a device, send, and the other side taps Accept.

## เชื่อมต่อกัน / Connecting

| วิธี | ใช้เมื่อ |
|---|---|
| **เครือข่ายเดียวกัน** | ต่อ Wi‑Fi เดียวกัน: เห็นกันอัตโนมัติ |
| **ห้องแบบตัวละคร** | หากันไม่เจอ หรืออยู่คนละเครือข่าย: กดปุ่มห้องด้านบน → **สร้างห้อง** จะได้ตัวละครอวกาศ 5 ตัว อีกเครื่องแค่แตะตัวละครให้ตรงตามลำดับ ไม่ต้องพิมพ์ |
| **สแกน QR** | กล้องอีกเครื่องสแกน QR ในหน้าต่างห้อง (มีปุ่มสแกนในแอปด้วย) |
| **แชร์ลิงก์** | ปุ่ม **แชร์ลิงก์** ส่งเข้า LINE / Messenger อีกฝ่ายแตะลิงก์ก็เข้าห้องเลย |
| **จับคู่ถาวร** | เครื่องที่ใช้กันประจำ: จับคู่ครั้งเดียว แล้วจะเห็นกันเองทุกครั้งแม้อยู่คนละเครือข่าย |

- รหัสตัวละคร: 5 ตัวจาก 16 ตัว (ราว 1 ล้านแบบ ห้องอยู่บน relay สาธารณะจึงต้องเดายากพอ) ใช้ได้ทุกภาษา แต่ละตัวมีสีประจำ หน้าจอทั้งสองเครื่องจึงเหมือนกัน
  ส่วนตัวกลม ๆ ที่หน้าตาคล้ายกันจะได้สีต่างกัน
- หลังส่งไฟล์ในห้องสำเร็จครั้งแรก แอปจะถามครั้งเดียวว่า "จับคู่ไว้ไหม" เพื่อครั้งหน้าไม่ต้องใช้รหัสอีก
  หรือจะจับคู่เองก็ได้: เลือกเครื่อง → **จับคู่ถาวร** → อีกเครื่องเช็กรหัสยืนยันแล้วกด **จับคู่**
- รหัสคำแบบเดิม (เช่น "แมว · ส้ม · ดาว") และรหัส 6 ตัวอักษรยังใช้ได้จาก **พิมพ์รหัสหรือวางลิงก์แทน**
- ออกจากห้อง หรือเปลี่ยนห้องระหว่างที่ยังโอนไฟล์อยู่ แอปจะถามยืนยันก่อน

## ส่งและรับไฟล์ / Sending and receiving

- **รับก่อนเสมอ**: ไฟล์ไม่วิ่งจนกว่าผู้รับจะกด "รับ" หน้าต่างรับจะบอกจำนวน ขนาด และสิ่งที่จะเกิดหลังกดรับ
- **ไฟล์ใหญ่**: ส่งเป็นชิ้นต่อเนื่อง มีความเร็ว เวลาที่เหลือ และปุ่มยกเลิกทั้งสองฝั่ง ผู้รับเก็บแบบนี้
  - ไม่เกิน 256 MB (และไฟล์ที่เก็บในหน้านี้รวมกันไม่เกิน 512 MB): เก็บไว้ในหน้าเว็บ ดูตัวอย่างได้ แล้วเลือกบันทึกเฉพาะที่ต้องการ
  - ใหญ่กว่านั้น บน Chrome/Edge (คอมพิวเตอร์): เลือกที่บันทึก แล้วเขียนลงดิสก์ตรง ๆ
  - เบราว์เซอร์อื่น: ดาวน์โหลดลงโฟลเดอร์ดาวน์โหลดโดยตรง
- **ไฟล์ที่ได้รับ** (ไอคอนถาดบนแถบด้านบน): อยู่ในรายการจนกว่าจะบันทึก ลบ หรือปิดหน้า
  - บอกขนาดที่ใช้หน่วยความจำ บันทึก / ลบทีละไฟล์ / ล้างทั้งหมดได้
  - ถ้าจะปิดหน้าแต่ยังมีไฟล์ที่ยังไม่ได้บันทึก แอปจะถามก่อน
- **ดูตัวอย่างในแอป**: รูป วิดีโอ เสียง PDF และไฟล์ข้อความ เลื่อนดูไฟล์ถัดไปได้
- **เมื่อการโอนสะดุด**: การ์ดการโอนจะบอกเสมอว่าเกิดอะไรขึ้นและจะเกิดอะไรต่อ
  - เน็ตหลุด: นับถอยหลังรอ แล้วส่งต่อจากจุดเดิมเองเมื่ออีกเครื่องกลับมา (ภายใน 90 วินาที)
  - ล้มเหลว / ยกเลิก / ไม่รับ: บอกว่าส่วนที่ค้างครึ่งทางถูกลบแล้ว พร้อมปุ่ม **ส่งอีกครั้ง** และ **ปิด** (ปิดการ์ดเฉย ๆ ไม่กระทบไฟล์)
  - ไฟล์ที่รับไม่ครบจะถูกลบทิ้งเสมอ รวมถึงไฟล์ใหญ่ที่เขียนลงดิสก์ จึงไม่มีไฟล์ว่างหรือไฟล์ครึ่งเดียวค้างในเครื่อง
- **ข้อความ (แชต)**: แต่ละเครื่องมีบทสนทนาของตัวเองในแผงด้านข้าง เป็นฟองแชต ลิงก์กดเปิดได้ คัดลอกได้ทีละข้อความ
  และตอบกลับได้ในช่องด้านล่าง (ร่างข้อความแยกตามเครื่อง; บนมือถือ Enter ขึ้นบรรทัดใหม่ ปุ่มส่งเป็นตัวส่ง)
  ข้อความใหม่ไม่เด้งหน้าต่างบังจอ: ขึ้นแจ้งเตือนเล็ก ๆ พร้อมปุ่ม "ดู" (กดการแจ้งเตือนของระบบก็เปิดแชตนั้น)
  และจุดนับข้อความที่ยังไม่อ่านบนตัวละครของเครื่องนั้น (เก็บไว้ในหน้านี้เท่านั้น ปิดหน้าแล้วหายไป)
- **แจ้งเตือน** (ปุ่มกระดิ่ง): มีคนส่งไฟล์มา (กดรับ/ไม่รับจากการแจ้งเตือนได้), ส่ง/รับเสร็จ, ไม่สำเร็จ,
  มีข้อความ, มีคนขอจับคู่ ฯลฯ เด้งเฉพาะตอนไม่ได้ดูหน้า Nearby อยู่ และต้องเปิด Nearby ค้างไว้ (ไม่มี push server)
- **ติดตั้งเป็นแอป (PWA)**: ปุ่ม "ติดตั้งแอป" บน Chrome/Edge/Android เปิดได้แม้ออฟไลน์
  บน Android เลือก Nearby จากเมนู "แชร์" ของแอปอื่นได้ด้วย (iPhone ยังไม่รองรับ)
- ระหว่างโอน แอปขอไม่ให้จอดับ (wake lock) เพราะมือถือมักตัดการเชื่อมต่อเมื่อจอดับ

## ความปลอดภัยและความเป็นส่วนตัว / Privacy and safety

- ไฟล์วิ่งตรงระหว่างเครื่องผ่าน WebRTC ซึ่งเข้ารหัสเสมอ ไม่มี server เก็บไฟล์
- **รหัสยืนยัน**: อีโมจิ 4 ตัวที่ได้จากการเชื่อมต่อของทั้งสองฝั่ง ถ้าสองเครื่องเห็นตรงกัน แปลว่าคุยกับเครื่องที่ถูกต้องจริง
- คนที่บังเอิญเข้าห้องเดียวกันส่งไฟล์มาเองไม่ได้ เพราะผู้รับต้องกด "รับ" ก่อนเสมอ
- **กันสแปม**: แต่ละเครื่องมีคำขอส่งไฟล์ค้างได้ทีละ 1 ชุด และคำขอจับคู่ 1 ครั้ง ที่เกินถูกปฏิเสธเอง ข้อความจำกัด 30 ข้อความต่อนาทีต่อเครื่อง
  คำขอที่ถูกรับไปแล้วไม่นับ ถ้ายังส่งถี่เกินไปภายในหนึ่งนาที จะระงับเครื่องนั้น 2 นาที และผู้ส่งจะเห็นว่า "ได้รับคำขอถี่เกินไป ลองใหม่อีกสักครู่"
- **เตือนไฟล์เสี่ยง**: หน้าต่างรับเตือนเมื่อมีไฟล์ที่รันโปรแกรมหรือเปิดเป็นหน้าเว็บได้ (เช่น .exe .apk .bat .html)
  และตัดอักขระที่มองไม่เห็นซึ่งใช้ปลอมนามสกุลไฟล์ (เช่นทำให้ "x.exe" ดูเหมือน ".jpg")
- ตัวอย่างไฟล์ไม่เคยเปิดไฟล์เป็นหน้าเว็บ (เช่น HTML) สคริปต์จากเครื่องอื่นจึงรันในหน้านี้ไม่ได้
- ชื่อ เครื่องที่เคยเจอ ชื่อเล่น และการจับคู่ เก็บอยู่ในเครื่องนี้เท่านั้น (localStorage)
- ถามยืนยันก่อนทำสิ่งที่ย้อนกลับไม่ได้: หยุดการโอนที่เริ่มแล้ว, ออก/เปลี่ยนห้อง, เลิกจับคู่, ลบไฟล์ที่ได้รับ (ทุกไฟล์), ล้างไฟล์ทั้งหมด
- **สิทธิ์ที่ขอ**
  - กล้อง: เฉพาะตอนสแกน QR อธิบายก่อนที่เบราว์เซอร์จะถาม ถ้าถูกบล็อกจะบอกวิธีเปิดสิทธิ์ (หรือใช้วิธีอื่นแทน)
  - ไฟล์: ไม่ต้องขอสิทธิ์ แอปอ่านเฉพาะไฟล์ที่ผู้ใช้เลือกเอง
  - การแจ้งเตือน: ขอเมื่อกดปุ่มกระดิ่งเท่านั้น

## หน้าตา / Look and feel

- สองธีม: **กลางคืน** (ค่าเริ่มต้น) และ **สนธยา** (สว่าง: ฟ้าม่วงครามไล่ไปลาเวนเดอร์และแสงพีช)
  ทั้งสองธีมมีดาวประกาย แสงขอบฟ้าของดาวเคราะห์จาง ๆ ที่ด้านล่าง และดาวเคราะห์สติกเกอร์เล็ก ๆ ตามขอบจอ (จอกว้าง)
  วาดลง canvas ครั้งเดียว จึงไม่กินแรงเครื่อง
- ตัวละครอวกาศ 16 ตัวสไตล์สติกเกอร์ชุดเดียวกัน กับสีพาสเทลอีก 8 สี เลยแยกได้ง่ายว่าเครื่องไหนเป็นของใคร
- จำเครื่องที่เคยเจอ: ป้าย "ใหม่ / เคยเจอ", เชื่อมต่อล่าสุดเมื่อไหร่, ส่ง/รับไปกี่ครั้ง และตั้งชื่อเล่นให้เครื่องอื่นได้
  เครื่องที่จับคู่แล้วอยู่วงในสุดของเรดาร์ เครื่องที่เคยเจออยู่วงกลาง เครื่องใหม่อยู่วงนอก
- เอฟเฟกต์เบา ๆ: จุดบนเรดาร์กะพริบตอนเส้นกวาดผ่าน, ดาวหางตอนเริ่มส่ง, ดาวแตกกระจายตอนส่งเสร็จ,
  ตัวละครกะพริบตาและยิ้มเมื่อชี้เมาส์ ใช้แค่ transform/opacity และปิดเองเมื่อเปิด "ลดการเคลื่อนไหว"
- **โหมดประหยัดพลังงาน** (ในโปรไฟล์: อัตโนมัติ / ประหยัด / เต็มที่): แบบอัตโนมัติจะเปิดเองเมื่อเครื่องสเปกต่ำ
  (≤ 2 คอร์ หรือ RAM ≤ 2 GB) หรือแบตเหลือ ≤ 20% และไม่ได้ชาร์จ
- ใช้ได้ทั้งภาษาไทยและอังกฤษ รองรับคีย์บอร์ดและโปรแกรมอ่านหน้าจอ
- โลโก้เป็นดาวเคราะห์ยิ้มมีเครื่อง 2 เครื่องโคจรรอบ (ใช้เป็นไอคอนแอปด้วย) แถบบนเป็นแคปซูลกระจกลอยตัว
- เรดาร์: ขีดสเกลรอบขอบ, วงแหวนสองชั้นหมุนสวนกันรอบตัวเรา, ลำแสงกวาดมีหางยาว และระลอกแสงจากตรงกลางเมื่อมีเครื่องใหม่เข้ามา
- แถบสถานะใต้เรดาร์: แสดงตัวละครของเครื่องที่เจอ (แตะเพื่อเลือก), จุดสามจุด "กำลังฟัง" ตอนยังไม่เจอใคร,
  ปุ่มเปลี่ยนตามสถานการณ์ (ใช้รหัสห้อง / ชวนเพื่อน) และคำแนะนำหมุนเวียนเมื่อหาไม่เจอสักพัก
- บนจอคอม ทั้งแอปพอดีหนึ่งหน้าจอไม่ต้องเลื่อน: เรดาร์ปรับขนาดตามพื้นที่ที่เหลือ
- บนมือถือ แถบด้านบนแบ่งเป็นสองแถว และป้ายชื่อบนเรดาร์จัดตำแหน่งเองไม่ให้ทับกันหรือล้นขอบ
- ระหว่างรอโหลด จะเห็นแถบสีเทาแทนข้อความที่ยังไม่มา

## ข้อจำกัด / Limitations

- Wi‑Fi ที่เปิด client isolation (เช่น Wi‑Fi สาธารณะบางที่) หรือเน็ตมือถือบางค่าย อาจต่อตรงกันไม่ได้ เพราะไม่มี TURN server
- "เครือข่ายเดียวกัน" ดูจาก public IP ถ้าอยู่หลังเราเตอร์เดียวกันแต่ออกเน็ตคนละทาง ให้ใช้ห้องแทน
- เบราว์เซอร์ที่ไม่มีทั้ง File System Access และ service worker (เช่น บางโหมดของ iOS) รับได้สูงสุด 2 GB ต่อครั้ง
- การแจ้งเตือนทำงานเฉพาะตอนที่ Nearby เปิดค้างไว้

## เบื้องหลัง / Under the hood

- Signaling ใช้ [Trystero](https://github.com/dmotz/trystero) ผ่าน Nostr relay สาธารณะ จึง host บน GitHub Pages ได้
- "เครือข่ายเดียวกัน" ใช้ hash ของ public IPv4 เป็นชื่อห้อง (ลองถาม ipify, icanhazip, ident.me ตามลำดับ)
  และเช็กใหม่เมื่อเปลี่ยนเครือข่าย แต่จะไม่ย้ายห้องระหว่างที่ยังโอนอยู่
- ห้องแบบรหัส: ชื่อห้องและรหัสผ่านได้จากรหัส (`p-galaxy-astro-luna-moon` หรือ `cat-orange-star`)
  การจับคู่ = secret ที่สุ่มแล้วเก็บไว้ทั้งสองเครื่อง ใช้สร้างห้องส่วนตัวที่ทั้งคู่เข้าทุกครั้งที่เปิดแอป
- ไบต์ของไฟล์วิ่งบน RTCDataChannel แยก (ชิ้นละ 64 KB) ส่วนข้อความควบคุมอยู่บน Trystero
  ผู้รับตอบ ack ทุก 1 MB และผู้ส่งค้างได้ไม่เกิน 8 MB จึงเร็วแต่ไม่ล้นหน่วยความจำ
- Service worker เก็บแอปไว้ใช้ออฟไลน์ (เช็กไฟล์ใหม่กับ server ทุกครั้ง หลัง deploy จึงไม่ปนไฟล์เก่า),
  รับไฟล์จากเมนูแชร์ และทำดาวน์โหลดแบบสตรีม

## Development

```bash
npm install
npm run serve        # http://localhost:8080
npm run build:vendor # rebuild vendor/vendor.js after upgrading trystero / qrcode-generator
node scripts/make-icons.mjs  # regenerate PNG icons
```

Testing with several "devices" on one computer: each origin has its own storage, so tabs on
`localhost:8080`, `127.0.0.1:8080`, `a.localhost:8080`, `b.localhost:8080`, … behave like different devices.
Join them all to the same room (e.g. `#r=cat-orange-star`) to keep tests away from real devices on your network.

After changing app files, bump `VERSION` in `sw.js` so installed copies pick up the new files.

### Project layout

| Path | What it does |
|---|---|
| `index.html`, `css/style.css` | Page markup, dialogs, and the night-radar theme (with a light "dawn" variant) |
| `js/app.js` | App wiring: state, sessions, rooms, dialogs, confirmations, paste/drop, transfers, pairing, install |
| `js/net.js` | Networking: network detection, Trystero rooms, offer/accept, file channel, resume, safety code, pair requests |
| `js/sinks.js` | Where received bytes go: memory, disk (File System Access) or streamed download; cleans up partial files |
| `js/words.js` | Room codes: 4-picture codes, 3-word codes (Thai / English, incl. Thai typed without spaces), old 6-letter codes |
| `js/pairing.js` | Saved pairings (localStorage) |
| `js/identity.js` | Random space names, mascot + colour per device |
| `js/known.js` | Devices seen before: badges, last seen, transfer counts, nicknames, "asked to pair" |
| `js/notify.js` | System notifications, vibration, app badge, on/off setting |
| `js/i18n.js` | Thai / English strings |
| `js/ui/radar.js` | Radar with device buttons (rings, label fitting, selection, progress, effects, keyboard) |
| `js/ui/panel.js` | Side panel: selected device / pick prompt / searching / help / error |
| `js/ui/status.js` | Hero heading and scan bar states (searching, found, none, error) |
| `js/ui/transfers.js` | Transfer cards (status, explanation, actions) for the tray and the side panel |
| `js/ui/inbox.js` | Received files list and the preview viewer |
| `js/ui/chat.js` | Per-device chat thread in the side panel (bubbles, links, copy, reply box) |
| `js/ui/scanner.js` | In-app QR scanner (BarcodeDetector or jsQR) |
| `js/ui/avatars.js` | The 16 space mascot SVGs |
| `js/ui/mascot.js` | Device-type icons and line icons |
| `js/ui/effects.js` | Effects on/off and power-saving mode |
| `js/ui/sky.js` | Starry background (canvas), twinkles, shooting stars |
| `sw.js` | Service worker: offline cache, share target, streamed downloads |
| `manifest.webmanifest`, `icons/` | PWA manifest and icons (`scripts/make-icons.mjs`) |

The site is plain HTML/CSS/JS with no build step. `vendor/vendor.js` is a pre-bundled copy of the two
dependencies and is committed so GitHub Pages can serve the repo root as-is.
